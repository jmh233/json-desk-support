JSON Desk Support

Format, read, and edit everyday JSON data. Report a problem or suggest an improvement through GitHub Issues.

Report an issueView existing issues

GitHub Issues are public. A GitHub account is required to submit a report.

What to include in your report

  • Your JSON Desk version and macOS version.
  • Steps to reproduce the problem, what you expected, and what actually happened.
  • A small example or screenshot, if needed to reproduce the issue.

Remove access tokens, passwords, real user details, and other private information before submitting. Use fictional data in examples.

Common questions

How do I format or compact JSON?

Paste your content, or use Open to choose a UTF-8 JSON file. Then select Format or Compact. The shortcuts are ⌘ ⇧ F for formatting and ⌘ ⇧ M for compacting. Choose 2 spaces, 4 spaces, or tabs for indentation.

What should I do when JSON is invalid?

Use the error message to check for missing commas, colons, or quotation marks. Select the line and column in the message to jump to the problem. If formatting fails, your original content stays intact; the app does not automatically repair or delete it.

Will large integers change?

Formatting and compacting work on the source text. They preserve the original spelling of large integers, decimals, and exponents, as well as field order and duplicate keys.

How is recovery different from saving a file?

Recovery data is stored on your device to help you continue unfinished work. It does not automatically overwrite your original files. Select Save to update a file, or Save as to choose another filename or location.

Do I need an account or an internet connection?

JSON Desk does not require an account. JSON documents are processed and saved locally, and everyday editing does not depend on a server. Submitting a GitHub Issue is a separate online service that you choose to use.
