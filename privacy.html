隐私政策

JSON Desk 的文档处理在你的设备上完成。

生效及更新日期：2026 年 10 月 28 日

适用范围

本政策说明 JSON Desk 桌面应用如何处理文档、本地工作区和偏好设置。开发者以 GitHub 账号 jmh233 提供技术支持。

应用不收集数据

JSON Desk 不收集个人信息，不把你粘贴、打开或编辑的 JSON 内容上传到开发者服务器。应用无需注册账号，日常使用不依赖服务器。

当前应用不包含广告、用户行为分析或跟踪 SDK，也不将文档内容出售或共享给第三方。

在设备上保存的内容

为了恢复上次的工作，应用会在本机保存当前文档、文件路径、最近保存的内容以及主题、缩进和窗口等偏好。上述工作区和恢复记录保留在本机，不会由应用同步至开发者服务器。

你可以使用“清空”移除当前编辑内容，并通过保存更新恢复状态。若要彻底移除历史恢复记录或导出的文件，需要同时删除相应的本机应用数据或文件；清空编辑区不会删除你另行保存的原文件。

本地文件访问

应用通过系统文件选择器或你主动拖入的文件获取文件访问权限，用于打开、保存和另存为 JSON 文件。自动恢复记录不会自动覆盖原文件。

技术支持与第三方网站

本支持网站通过 Netlify 或 GitHub Pages 提供静态页面托管，反馈入口由 GitHub 提供。如果你主动提交 GitHub Issue，其正文和附件会在公开仓库中展示；请勿提交密码、访问令牌、真实用户数据或其他敏感内容。开发者会使用你主动提供的反馈来排查问题或答复请求。

访问本支持网站时适用相应托管服务商的隐私政策；使用 GitHub Issues 时适用 GitHub 的隐私政策与服务规则。这些在线服务与 JSON Desk 在本机处理文档的行为不同。

政策更新

如果后续版本改变数据处理方式，本页将同步更新，并在顶部注明更新日期。

联系开发者

如对本政策或应用的数据处理方式有疑问，请通过 GitHub Issues 提交问题。提交需要 GitHub 账号，请仅提供可公开的信息。
