Privacy policy

JSON Desk processes your documents on your own device.

Effective October 28, 2026. Last updated October 29, 2026.

Scope

This policy describes how the JSON Desk desktop app handles documents, local workspace data, and preferences. The developer provides support through the GitHub account jmh233.

The app does not collect data

JSON Desk does not collect personal information or upload JSON that you paste, open, or edit to developer-operated servers. No account is required, and everyday use does not depend on a server.

The current app does not include advertising, usage analytics, or tracking SDKs. It does not sell or share your document content with third parties.

Data stored on your device

The app saves local recovery data and preferences so you can continue unfinished work. These records may include documents, file paths, the last saved contents, and preferences such as theme, interface language, indentation, and window settings. The app does not sync these records to developer-operated servers.

Clearing an editor does not delete files you saved separately. To completely remove local recovery records or exported documents, remove the corresponding application data or files from your device.

Local file access

The app accesses files that you choose through the system file picker or deliberately drag into the app. It uses that access to open, save, or save a copy of JSON files. Recovery records do not automatically overwrite your original files.

Support and third-party websites

This support website is hosted as static pages on Netlify or GitHub Pages. The feedback service is provided by GitHub. If you submit a GitHub Issue, its text and attachments are visible in a public repository. Do not include passwords, access tokens, real user data, or other sensitive information. The developer uses the feedback you choose to provide to investigate problems or respond to requests.

Visits to this website are subject to the relevant hosting provider’s privacy policy. GitHub Issues are subject to GitHub’s privacy policy and service rules. These online services are separate from JSON Desk’s local document processing.

Policy updates

If a later version changes how data is handled, this page will be updated and the revision date will appear above.

Contact the developer

For questions about this policy or the app’s data handling, open a GitHub Issue. A GitHub account is required. Only include information that you are comfortable sharing publicly.
