JSON Desk 技术支持

格式化、阅读与修改日常 JSON 数据。遇到问题，或有想改进的地方，可以通过 GitHub Issues 联系开发者。

提交问题查看已有问题

反馈入口为公开的 GitHub Issues，提交需要 GitHub 账号。

反馈时提供这些信息

  • JSON Desk 版本，以及 macOS 版本。
  • 操作步骤、预期结果和实际发生的情况。
  • 如有必要，附上能够复现问题的精简示例或截图。

请在提交前移除访问令牌、密码、真实用户资料和其他不宜公开的内容。可以使用虚构数据制作示例。

常见问题

怎样格式化或压缩 JSON？

粘贴内容，或通过“打开”选择 UTF-8 JSON 文件，然后点击“格式化”或“压缩”。格式化快捷键为 ⌘ ⇧ F，压缩为 ⌘ ⇧ M。缩进可选择 2 空格、4 空格或 Tab。

显示格式错误怎么办？

根据错误提示检查缺少的逗号、冒号或引号。点击提示中的行列位置，可以回到对应内容。格式化失败时，原始内容会保留，不会自动修复或删除。

长整数会被改变吗？

格式化与压缩按源文本处理，保留长整数、小数及指数的原始写法，也保留字段顺序与重复键。

自动恢复和保存文件有什么区别？

恢复记录保存在本机，方便继续未完成的工作；它不会自动覆盖原文件。要更新原文件，请点击“保存”；要选择新文件名或位置，请使用“另存为…”。

需要账号或联网吗？

JSON Desk 无需注册账号，JSON 文档在本机处理和保存，日常编辑不依赖服务器。通过本网站提交 GitHub Issue 属于你主动使用的独立在线服务。

文档留在本机

关于 JSON 内容、本地恢复记录和文件访问权限，请阅读 JSON Desk 隐私政策。
